# 拾记 PikNote 1.1.1

## 修复

- 拾记的程序文件不完整时（比如更新时被替换了一半），打开笔记会直接退出；现在会在窗口顶部提示“编辑器文件丢失，请重新安装拾记”，笔记文件不受影响

1.1.0 的全部新功能都在这一版里，详见 [1.1.0 的更新说明](v1.1.0.md)。

# PikNote 1.1.1

## Fixed

- If PikNote’s app files were incomplete (for example, half-replaced during an update), opening a note made the app quit. It now shows “The editor files are missing. Please reinstall PikNote.” at the top of the window instead. Your notes are not affected

Everything new in 1.1.0 is included; see the [1.1.0 release notes](v1.1.0.md).
