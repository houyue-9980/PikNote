# 拾记 PikNote 2.1.0

## 新功能

- **书架可以收起**：主界面每层书架的标题左边多了一个小三角，点标题就能收起 / 展开这一层，像抽屉一样平滑地收拢。按住 ⌥ 点，所有书架一起收起 / 展开
- 收起后，标题旁边会显示这层有几篇笔记，以及前几篇的表情，大概知道里面放了什么
- 收起的状态会记住，下次打开还是收着的；收起的书架照样可以把文件拖进去

# PikNote 2.1.0

## New

- **Collapsible shelves**: each shelf title on the main window now has a small triangle. Click the title to collapse or expand that shelf, which slides shut like a drawer. ⌥-click to collapse or expand all shelves at once
- A collapsed shelf shows how many notes it holds and the emojis of the first few, so you can still tell what’s inside
- Collapsed shelves stay collapsed the next time you open PikNote, and you can still drag files onto them
