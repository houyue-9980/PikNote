# 拾记 PikNote 1.1.0

下载 `PikNote-1.1.0.dmg`，拖进“应用程序”替换旧版即可。笔记文件和书架设置完全兼容，不需要做任何转换。

## 新功能

- **重命名笔记**：在书架上或书架管理里右键 → 重命名…；笔记窗口里点标题右边的 ▾，或点底部状态栏的文件名，或用菜单 文件 → 重命名…。表情、底色、在书架上的位置都会保留
- **链接右键菜单**：右键链接可以打开、重命名（改显示的文字和地址）、拷贝地址、去掉链接
- **没有 https:// 的网址也能打开**：比如写的是 `bilibili.com`，在本地找不到同名文件时会直接用浏览器打开，不再报错
- **表格**：选中整行、整列或整张表后，按 delete 或 ⌘X 直接删掉，不用再去工具栏
- **拖动选中的内容**：在蓝色选区里按住拖到别处，按住 ⌥ 是复制一份；拖动时有一条竖线提示会放在哪
- **书架**：主页上的笔记图标可以拖到别的书架，或拖到别的图标前面调整顺序；整层归档的书架可以直接拖回左边放回去
- **图标底色可以选任意颜色**：底色那一排最后多了“…”，打开系统颜色面板；书架上右键也能直接改图标和底色
- **公式快捷栏（⌘⇧M）从 46 条扩充到 129 条**：新增全部希腊字母、集合符号（∈ ⊆ ∪ ∩ ℝ …）、逻辑和证明符号（∀ ∃ ⇒ ⇔ ∴ ∎ …），中文、英文、拼音都能搜
- **笔记侧栏底部**分成“关闭”和“库”两个按钮，整块都能点

## 修复

- 在表格里编辑时看不到光标
- 分界线有时点不中、没法和文字一起拖选、几条连在一起时没法只选其中几条
- 分界线在笔记最后时下面放不了光标、删不掉
- 选区跨好几行时，有些蓝色的地方按住拖不动
- 删除表格的表头行会出错
- 从 OneDrive 等网盘里拖进来的图片只显示名字（现在会先下载再复制）；图片读不到时会写清楚找不到哪个文件
- 底部状态栏在护眼主题下有一块白条

# PikNote 1.1.0

Download `PikNote-1.1.0.dmg` and drag it into Applications to replace the old version. Your notes and shelf settings work as they are; nothing needs converting.

## New

- **Rename notes**: right-click a note on the bookshelf or in Manage Shelves → Rename…; in a note window, use the ▾ next to the title, click the file name in the status bar, or File → Rename…. The emoji, color and position on the shelf are kept
- **Link context menu**: right-click a link to open it, rename it (text and address), copy its address, or remove it
- **Links without https:// open in the browser**: e.g. `bilibili.com` opens the website when there's no local file with that name, instead of showing an error
- **Tables**: select whole rows, columns or the whole table and press Delete or ⌘X to remove them
- **Drag a selection**: press inside the blue selection and drag it elsewhere; hold ⌥ to copy. A line shows where it will land
- **Bookshelf**: drag note icons to another shelf or onto another icon to reorder; drag an archived shelf back to the left to restore it
- **Any icon color**: a “…” after the color swatches opens the system color panel; right-click a note on the bookshelf to change its icon and color
- **Formula bar (⌘⇧M) grows from 46 to 129 entries**: all Greek letters, set notation (∈ ⊆ ∪ ∩ ℝ …), logic and proof symbols (∀ ∃ ⇒ ⇔ ∴ ∎ …), searchable in Chinese, English or pinyin
- **The note sidebar footer** is now two buttons, Close and Library, each fully clickable

## Fixed

- No blinking cursor while editing a table
- Divider lines were hard to click, couldn't be drag-selected with text, and a run of them couldn't be partly selected
- A divider at the end of a note left no place for the cursor and couldn't be deleted
- Parts of a long, multi-line selection couldn't be dragged
- Deleting a table's header row caused an error
- Images dragged in from OneDrive and other cloud folders showed only their name (they're now downloaded before copying); a missing image now says which file it can't find
- A white strip under the status bar in the Sepia theme
