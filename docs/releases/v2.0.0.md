# 拾记 PikNote 2.0.0

## 新图标

拾记的图标从“拾”换成了“**记**”。

拾记是拾系列的第一款软件，之后还会有更多。从这一版起，拾系列的每款软件都用自己名字的第二个字做图标（拾记 → 记），白底、宋体、右下角那块橙色小方块不变，它是整个系列共同的标记。

更新后，程序坞（Dock）和“应用程序”里的图标会变成新的样子。如果还显示旧图标，把 PikNote 从程序坞移除后重新打开即可。

笔记、书架、设置都不受影响，功能和 1.2.0 一样。

# PikNote 2.0.0

## New icon

PikNote’s icon changes from 拾 to **记** (“note”).

PikNote is the first app in the 拾 series, with more to come. From this release on, every app in the series uses the second character of its name as its icon (拾记 → 记). The white tile, the serif character and the small orange square in the corner stay the same; the square marks the whole family.

After updating, the icon in the Dock and Applications changes to the new design. If you still see the old icon, remove PikNote from the Dock and open it again.

Your notes, shelves and settings are untouched, and features are the same as in 1.2.0.
