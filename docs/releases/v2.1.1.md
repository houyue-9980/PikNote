# 拾记 PikNote 2.1.1

## 修复

- 在主页拖动笔记图标调整顺序或换书架时，松手后原地会残留一个小图标，看起来像出现了两个。现在拖动由拾记自己处理：一个和原图标一样的影子跟着鼠标走，经过别的图标时左边出现蓝线、经过书架空白处时整层高亮，松手后影子直接消失，图标同时出现在新位置

# PikNote 2.1.1

## Fixed

- When you dragged a note icon on the main window to reorder it or move it to another shelf, a small copy lingered where you let go, so it looked like there were two. Dragging is now handled by PikNote itself: a copy of the icon follows the mouse, a blue line shows where it will go (or the whole shelf highlights when dropping at its end), and on release the copy disappears as the icon appears in its new place
