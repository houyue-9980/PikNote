# PikNote 2.0.3

## Changed

- The “Background” color option is gone from Settings → Personalize. Each theme now always uses its own page color (white for Light, dark gray for Dark, warm paper for Sepia), so things look more consistent. If you had changed it, it goes back to the theme’s color after updating; your heading colors are kept
